# Trade roots — the only vocabulary a customer lexicon may be built from.
#
# WHY THIS FILE EXISTS
# Lexicons used to be derived from a firm's own tender texts with only a
# rarity sieve in front of them. Rarity is not meaning: 'derzeit' sits in
# 0.97% of store lots and 'estrich' in 1.88%, so the sieve rated the filler
# word ABOVE the trade word. Lexicons filled with office boilerplate
# ("behoerde", "berufsbildung", "nachstehend") and then convicted
# wrong-trade lots -- a flooring firm was offered electrical and heating
# work because it shared its buyer's standard opening paragraph.
#
# WHY NOT DERIVE IT FROM CPV
# CPV-45 mixes two axes: 484 of its 822 labels name what is BUILT
# (Schulgebaeude, Polizeireviere) and only 330 name the WORK done. It also
# names no MATERIALS at all -- no linoleum, no kautschuk, no gipskarton --
# and uses only one name per trade, so Schreiner, Spengler, Flaschner and
# Anstreicher are absent while Tischler, Klempner and Maler are present.
#
# WHY NOT LET THE EMBEDDER GENERALISE IT
# Measured on jina-v2-base-de (noise floor for unrelated pairs: mean 0.133,
# max 0.214): trade synonyms score 0.29-0.89 -- real signal, but only 2 of
# 12 clear the 0.80 synonym bar, and the misses are the regional names that
# matter (anstreicher/maler 0.289, spengler/klempner 0.395, schreiner/
# tischler 0.525). Material-to-trade is at noise: linoleum/bodenbelag
# 0.108, dehnfuge/estrich 0.148. Nearest-neighbour lookups return
# schreiner->Faulbehaelter and sockelleiste->Standseilbahn. The list must
# therefore carry the meaning; the embedder may only tolerate spelling.
#
# HOW THIS LIST WAS BUILT
# It is WRITTEN, not derived. No program can produce it: CPV lacks the
# materials and the regional trade names, and the embedder cannot supply
# them either (see above). So the list is the VOB/C trade set written out
# by hand -- every Gewerk, its regional variants, its materials and its
# characteristic components -- covering trades no current customer has,
# because the next customer will.
#
# Two inputs informed the writing without deciding it: the CPV-45 labels
# that name a work, and a pass over the store for words putting >=30% of
# their occurrences in a single trade. The latter suggested real
# vocabulary nobody lists from memory (fangspitzen, kulissenschalldaempf,
# tackerplatte, hochkantlamellenparkett) -- and, ranked just as highly,
# place names (denkendorf, wolfratshausen) and contract words
# (angebotspreis, vertragsfristen). That is exactly why the suggestions
# were read rather than merged: a miner proposes, a person accepts.
#
# 2026-08-07 -- EXTENDED FROM SIX TRADES TO ALL OF THEM
# The first writing was made against the six live subscriptions, so it is
# thorough exactly where they work -- screed, flooring, carpentry,
# guardrails -- and thin everywhere else. The store holds ~1,300 repeat
# winners spanning every construction trade, and a trade whose vocabulary
# is missing does not get a small lexicon, it gets an empty one. This
# round writes out the remainder of the VOB/C set on the same principle:
# the Gewerk, its regional names, its materials, its characteristic
# components. Added trades include roofing detail (Gaube, Traufe, Ortgang,
# Attika), timber engineering (Brettschicht, Leimbinder, Fachwerk),
# masonry consumables (Moertel, Verfugung), plumbing/drainage (Abscheider,
# Hebeanlage, Rueckstau), heat generation (Fernwaerme, BHKW, Geothermie,
# Pellet), electrical distribution (Unterverteilung, Potentialausgleich,
# Erdung, Leerrohr), PV beyond the panel (Wechselrichter, Speicher),
# Raumausstatter (Polster, Gardine, Tapete), Ofenbau/Hafner, Vergolder and
# Restaurator, Terrazzo, Mosaik, Treppen, Balkone, Schwimmbadtechnik,
# sports fitout (Prallwand, Tribuene, Turngeraet), water engineering
# (Schleuse, Renaturierung) and Bauendreinigung.
#
# Two existing entries were repaired in the same pass:
#   pfosten-riegel  could never match. Candidates are single tokens
#                   ([a-zaeoeuess]{3,}); the hyphen ends the token, so no
#                   candidate ever contains the string. Replaced by
#                   'pfosten' and 'pfostenriegel'.
#   rollladen       misses the pre-1996 spelling, which the corpus still
#                   writes. 'rolladen' added alongside it.
# Likewise the door roots were whole compounds (tueren, tuerblatt,
# haustuer ...), so Schiebetuer, Stahltuer and Tuerschliesser fell through;
# the bare root 'tuer' is still refused because it matches natuerlich, so
# the missing compounds are named instead.
#
# HOW IT IS USED
# A candidate keyword survives only if it CONTAINS one of these roots.
# Roots, not whole words, because German carries the trade in the
# compound's modifier: Holz|bau, Holz|arbeiten and Brettsperr|holz share
# only "holz". Written folded (ae/oe/ue/ss); matching folds both sides, so
# Tuer/Tür and Fussboden/Fußboden each need one entry. Generic heads
# (bau, arbeiten, anlagen, installation, montage, erneuerung, sanierung)
# are ABSENT BY DESIGN -- they name no trade and would match everything.
#
# LIMITS AND EXCEPTIONS
# A word can contain a trade root and still not name the trade: Klassen|
# zimmer is a room, not carpentry, and Hain|holz is a village. Lines
# beginning with "-" are exceptions -- a candidate containing one is
# rejected even if it also contains a root. Keep that list short: it is a
# patch for compound collisions, not a second vocabulary. Everything else
# still runs on top (buyer diversity, store rarity), and jargon whose root
# is missing is simply lost -- add the root, do not weaken the rule.
# Reviewed by reading; re-running the miner proposes candidates, it does
# not accept them.
#
# Roots shorter than six characters are the ones that bite (ramm matched
# Programm, tore matched Motoren, tuer matched natuerlich). The short ones
# kept here are: dusch, gaube, trauf, staud, mulch, and the two acronyms
# bhkw and wdvs, which carry no other reading in German.
