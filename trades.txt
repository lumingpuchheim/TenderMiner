# Trades — the named Gewerke the market view reports and ranks.
#
# WHY THIS FILE EXISTS
# The store has no trade column. cpv3 gives five buckets (450 general, 451
# site preparation, 452 civil, 453 installation, 454 finishing) — too coarse
# to name a Gewerk, and CPV is a filing decision made by the buyer's clerk,
# not a description of the work: of the store lots whose TITLE says
# Blitzschutz, only 64% carry 45312310 as their main code. So a trade is
# defined here, by the words the buyer wrote, and matched as substrings
# against the folded notice text (evidence.fold — Fussboden and Fußboden are
# one word, so each spelling needs one entry, not two).
#
# WHO OWNS IT
# A person. market.py can propose words (`python market.py suggest <trade>`
# ranks vocabulary by how much more often it appears inside the trade than
# outside it) but it never adds one. A ranking of trades is a decision about
# where to spend a sales week; it may not rest on a word list nobody read.
#
# FORMAT
#   == Group name         starts a group of trades. Display only, and read in
#                         exactly one place: the public index at /gewerke/,
#                         which lists 54 trades and needs headings to be
#                         readable. Nothing selects, ranks or measures by it.
#   = Trade name          starts a trade; everything until the next "=" is its
#   wort                  match word — substring, so plurals and compounds
#                         need no entry (blitzschutz catches
#                         Blitzschutzanlage, Blitzschutzarbeiten)
#   -wort                 exclusion — a lot containing this is NOT this trade,
#                         even if another word matched
#   # ...                 comment
#
# RULES A WORD MUST FOLLOW
# * At least 5 characters. Shorter substrings hit inside unrelated compounds.
# * It names the WORK or its MATERIAL, never the building: "schulgebaeude" is
#   not a trade, "estrich" is.
# * Prefer the specific over the generic. "glas" matches Glasfassade and
#   Douglasie; "isolierglas" matches glazing. "zimmer" is a room in
#   Klassenzimmer; "zimmermann" is the carpenter.
# * Every word here should also appear in cpv_trade_roots.txt, which is the
#   reviewed vocabulary. That is a convention, not a constraint the code
#   enforces: the roots file is construction because today's store is, and a
#   trade outside construction must be writable here the day the store widens.
#
# OVERLAP IS REAL, NOT AN ERROR
# "Elektro, Blitzschutz, Datennetz, SiBe" is one lot in three trades. It is
# counted in all three and market.py reports how much of a trade overlaps
# with its neighbours. Do not chase exclusivity by deleting words — you would
# lose the lot from the trade that actually wants it.

# IT AND SOFTWARE
#
# The store stopped being construction-only on 2026-08-22: cycle.py downloads
# CPV 45, 48 (Softwarepakete) and 72 (IT-Dienste), and 11,828 of its lots are
# now IT. Nothing above claimed 81 of them, so a software firm searching for
# its own trade found a site made entirely of Estrich and Dachdeckung.
#
# The rules do not change. A trade is still the words the buyer wrote in the
# title, still at least 5 characters, still specific over generic. Two notes
# that are particular to this half:
#
# * The words are English as often as German, because the buyers write them
#   that way ("managed service", "storage", "security"). That is the corpus,
#   not a preference.
# * cpv_trade_roots.txt is construction vocabulary and none of these words are
#   in it. The header above says that convention holds only while the store
#   does; it stopped holding here.
#
# COLLISIONS, the same shape as Sportgeraete/Transportgeraete above:
#   server   is inside wasserversorgung, glasfaserverkabelung and
#            laservereinzelung — three construction words that have nothing to
#            do with a server. Hence the exclusions on that trade.
#   erp      is inside Koerperschaft, Sperrung and a dozen others; there is no
#            safe substring for ERP, so the systems are named instead
#            (erp-system, s/4hana, successfactors).
#   siem     is inside Siemens. Not used.
#   wlan     is four characters, under the minimum; "wlan-" is what is left.
#
# OVERLAP with Elektro and Datennetz is real and stays: an "aktive
# Netzwerktechnik" lot is bid by a systems house and by an electrician, and it
# is counted in both trades. About a fifth of "Netzwerk und WLAN" is cabling
# work filed under CPV 45 — that is the market, not a matching error.
